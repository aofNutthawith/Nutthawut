End User Support – Fujitsu

April 2025 – Present

Role Overview

Provide enterprise-level IT support in a corporate environment. Responsible for managing Microsoft 365 services, troubleshooting hardware and software issues, and ensuring smooth IT operations for end users. Support both onsite and remote environments while maintaining IT asset control and compliance.

Core Responsibilities

  • Manage Microsoft 365 environment (Exchange, Teams, OneDrive, SharePoint)
  • Troubleshoot Windows OS, enterprise applications, and hardware devices
  • Provide onsite and remote support for end users
  • Handle IT asset management and lifecycle tracking
  • Support network connectivity issues and basic server troubleshooting
  • Coordinate with infrastructure and global IT teams for escalated incidents
  • Ensure minimal downtime and maintain service-level standards

Technical Environment

Microsoft 365 Windows 10/11 Active Directory LAN / Network Support Hardware Troubleshooting Enterprise IT Support

Key Contributions

  • Improved response time for IT incidents through structured troubleshooting process
  • Maintained high user satisfaction with consistent service delivery
  • Reduced recurring issues by identifying root causes and preventive actions
